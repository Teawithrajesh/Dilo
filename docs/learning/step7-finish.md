# Step 7 — Final touch (seekhne ke notes)

## 1. क्या बनाया?
Profile edit, privacy settings (anonymous by default, data download, account delete), report और block, moderator dashboard, और आपका admin dashboard। साथ में accessibility और speed की जाँच।

## 2. क्यों बनाया?
परिवार तभी भरोसा करेगा जब उसे अपने data पर control हो, गलत चीज़ की शिकायत कर सके, और DILO खुद उनकी private बातें न देखे।

## 3. कैसे काम करता है?
- **Report** community के moderators के पास जाता है; वे "रखो" या "हटाओ" चुनते हैं और report करने वाले को बताया जाता है।
- **Admin** को सिर्फ़ गिनती और report का छोटा सार दिखता है — private community अंदर से नहीं खुलती। यही DPDP Act की भावना है।
- **axe** एक robot है जो देखता है कि screen reader वाले लोग भी app चला सकें (नाम, रंग, labels)।
- **4G test**: धीमे internet और धीमे phone की नकल करके page का समय नापा: ~2.3 सेकंड।

## 4. आपने क्या सीखा?
- "Privacy by design": admin को भी कम से कम दिखाओ।
- Accessibility robot ने 4 असली गलतियाँ पकड़ीं जो आँख से नहीं दिखतीं।
